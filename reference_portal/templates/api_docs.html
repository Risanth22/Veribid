Company Reference REST API

HTTP endpoints exposed by the Reference System and consumed by the Main Audit Application.
Data Flow Architecture: Main Audit Application → REST API (Port 5001) → Reference Database
GET /api/reference/companies

Lists all trusted reference companies. Supports query parameter ?q=search_term.

{ "count": 2, "data": [...], "success": true }
GET /api/reference/company/{identifier}

Fetches trusted company records by GSTIN, CIN, company_id, or name.

{ "data": { "company_id": "COMP-001", "company_name": "ABC Technologies Pvt Ltd", "gstin": "33ABCDE1234F1Z5", "cin": "U12345TN2020PTC123456" }, "source": "gstin", "success": true }
GET /api/reference/company/{company_id}/certificates

Returns trusted certificates metadata for the specified company.

GET /api/reference/company/{company_id}/documents

Returns list of registered reference files and paths.
